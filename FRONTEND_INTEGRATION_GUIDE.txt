# Frontend Integration Guide - Cluso Node Layer (Production Flow)

This guide outlines how to consume recording data and AI-processed instructions from the Node.js backend. The new flow prioritizes **immediate playback** of raw media followed by **background AI updates**.

## Connection Details

- **Backend URL**: `http://localhost:3000`
- **Socket.IO Event**: `register(sessionId)`

### 1. Registration
Immediately after connecting, register the `sessionId` to start receiving events.

```javascript
const socket = io('http://localhost:3000');
socket.emit('register', 'session_123_abc');
```

---

## The "Raw-First" Flow

To minimize user wait time, the system now works in two stages:

### Stage 1: Immediate Raw Playback
As soon as the recording is finalized, the backend sends the raw video and audio URLs.

1.  **`video` event (isRaw: true)**:
    *   `path`: An S3 signed URL for the raw video file.
    *   `isRaw`: `true`
2.  **`audio` event (isRaw: true)**:
    *   `path`: An S3 signed URL for the raw microphone audio.
    *   `isRaw`: `true`

**Implementation Tip**: Load these into your player immediately so the user can review their recording while AI processes in the background.

### Stage 2: Background AI Updates
A few seconds later, the AI processing will finish and send:

1.  **`audio` event (AI processed)**:
    *   `path`: S3 signed URL for the **generated narration**.
    *   `isRaw`: `false` (or undefined)
2.  **`instructions` events**:
    *   Contains the timeline of actions, visual effects, and narrations.

---

## Event Structures

### 1. `video`
```json
{
  "filename": "video_session_123.webm",
  "path": "https://s3.amazonaws.com/bucket/recordings/session_123/video.webm?Signature=...",
  "isRaw": true,
  "metadata": { ... },
  "timestamp": "2025-..."
}
```

### 2. `audio`
```json
{
  "filename": "audio_session_123.webm",
  "path": "https://s3.amazonaws.com/bucket/recordings/session_123/audio.webm?Signature=...",
  "isRaw": true, // false for AI generated narration
  "text": "Full transcribed script (if generated)",
  "timestamp": "2025-..."
}
```

### 3. `instructions`
Handled by type:
- **Default**: Player actions (`click`, `scroll`).
- **`type: "displayEffect"`**: Visual highlights/zooms.
- **`type: "narrations"`**: Full script timeline.

---

## URL Handling Logic

All `path` values sent by the server are now **Full URLs** (either S3 Signed URLs or direct Python server URLs). 

**Recommended logic:**
```javascript
socket.on('video', (data) => {
    // data.path is a full S3 signed URL. Use it directly.
    videoPlayer.src = data.path;
    if (data.isRaw) {
        console.log("Playing raw preview...");
    }
});

socket.on('audio', (data) => {
    // data.path is a full URL.
    audioPlayer.src = data.path;
});
```
